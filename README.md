# 오늘의 1위 — 운영 안내서

유튜브·쇼츠·인스타 릴스 조회수 순위 사이트입니다. 이 폴더를 그대로 GitHub에 올리면 무료로 운영할 수 있습니다.

## 어떻게 돌아가나요

```
방문자 브라우저 ──▶ 내 도메인 (GitHub Pages, 무료 호스팅)
                        │  index.html + data/*.js 를 읽어 화면에 표시
                        │
GitHub Actions (30분마다) ──▶ YouTube Data API ──▶ data/live.js 저장
   └ API 키는 저장소 Secrets 에만 있음 → 방문자에게 절대 노출되지 않음
```

- **순위 목록** `data/rankings.js` — 매일 0시 갱신 (아래 7번)
- **유튜브 실시간 조회수** `data/live.js` — 서버가 약 30분마다 자동 갱신
- **해설 글** `posts/` + `data/posts.js`
- **운영자 정보·광고 설정** `site.config.js` ← 이 파일 하나만 고치면 됩니다

---

## 1. GitHub에 올리기 (약 10분)

1. https://github.com 가입 후 오른쪽 위 **+ → New repository**
2. 이름 예: `today1` / **Public** 선택 → Create
3. **GitHub Desktop** 프로그램으로 이 폴더 내용을 저장소에 올립니다.
   - 웹 화면 업로드는 `.github` 처럼 점(.)으로 시작하는 폴더가 빠질 수 있어 GitHub Desktop을 권장합니다.
4. 저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `/(root)` → Save
5. 몇 분 뒤 `https://내아이디.github.io/today1/` 에서 사이트가 열립니다.

## 2. 유튜브 API 키 등록 (약 10분)

1. https://console.cloud.google.com → 새 프로젝트 만들기
2. **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용**
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
4. 만든 키의 **키 제한** → API 제한: `YouTube Data API v3`만 선택 → 저장
   - 서버에서만 쓰는 키라 웹사이트 주소 제한은 걸지 않습니다.
5. GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `YOUTUBE_API_KEY` / Secret: 위에서 만든 키
6. 저장소 **Actions** 탭 → `유튜브 조회수 자동 갱신` → **Run workflow** 로 한 번 실행해 초록색 체크가 뜨는지 확인

> 1회 실행에 약 7단위를 씁니다. 30분마다 돌면 하루 약 340단위로, 무료 한도(하루 10,000단위)의 4% 수준입니다.

## 3. 내 도메인 연결 (구매 후 약 30분, DNS 반영은 최대 24시간)

1. 도메인 업체(가비아, 카페24, 후이즈, Cloudflare 등)에서 도메인을 삽니다.
2. **먼저** GitHub 저장소 **Settings → Pages → Custom domain** 에 `내도메인.com` 입력 → Save
   - 이 순서를 지켜야 남이 내 도메인을 가로채는 위험이 없습니다.
3. 도메인 업체의 **DNS 관리**에서 아래처럼 등록합니다.

   | 종류 | 호스트 | 값 |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | 내아이디.github.io |

4. 반영되면 Pages 화면에서 **Enforce HTTPS** 체크 (자물쇠 주소 https:// — 광고 승인에 필수)
5. `robots.txt`, `sitemap.xml` 안의 `example.com` 을 내 도메인으로 바꿉니다.

## 4. 운영자 정보 입력

`site.config.js` 를 열어 채웁니다. 소개·개인정보처리방침·하단에 자동 표시됩니다.

```js
operator: "홍길동",
email: "contact@내도메인.com",
domain: "https://내도메인.com",
```

비워 두면 해당 칸에 노란색으로 “(site.config.js에 입력 필요)”가 보입니다. **광고 신청 전에 반드시 채우세요.**

## 5. 카카오 애드핏 붙이기

1. https://adfit.kakao.com 에서 카카오 계정으로 가입
2. **매체 등록 → Web** → 내 도메인 주소와 카테고리(엔터테인먼트 등) 입력
3. **광고단위 만들기** — 광고 자리 3곳 × PC/모바일 = 최대 6개
   - PC: `728x90`, 모바일: `320x100` 권장
   - 자리: `top`(검색창 아래), `mid`(순위표 아래), `bottom`(맨 아래·해설 페이지)
4. 받은 광고단위 ID(DAN-으로 시작)를 `site.config.js` 에 넣습니다.
   ```js
   top: { pc: { id: "DAN-xxxx", w: 728, h: 90 }, mobile: { id: "DAN-yyyy", w: 320, h: 100 } },
   ```
5. 저장해서 올리면 광고 호출이 시작되고, 그 뒤 심사가 진행됩니다(대개 영업일 1~2일).
- ID가 없는 자리는 화면에 나타나지 않으므로 처음엔 1~2곳만 넣어도 됩니다.
- 광고는 재생 버튼·플레이어와 떨어진 곳에만 배치했습니다. 실수 클릭을 유도하는 배치는 제재 대상이니 위치를 옮길 때 주의하세요.

## 6. 애드센스 신청 (방문자가 쌓인 뒤)

신청 전 점검표:

- [ ] 내 도메인 + https 연결 (3번)
- [ ] 소개·개인정보처리방침 페이지에 운영자·이메일 입력 (4번)
- [ ] 해설 글이 꾸준히 쌓여 있음 (최소 몇 주 동안 매일)
- [ ] 모든 메뉴·링크가 정상 작동
- [ ] 방문자가 검색·공유로 꾸준히 들어옴 (구글 서치 콘솔에 사이트맵 등록 권장)

승인 절차:

1. https://adsense.google.com 가입 → 사이트 추가
2. 받은 게시자 ID(`ca-pub-숫자`)를 `site.config.js` 의 `adsenseClient` 에 넣고 올리기 (사이트 확인 코드 역할)
3. 승인되면 `ads.txt.example` → `ads.txt` 로 이름을 바꾸고 pub 번호를 채워 올리기
4. 애드센스 자동 광고를 켜면 애드핏과 함께 너무 많은 광고가 뜰 수 있으니, 애드센스 화면에서 광고 수를 조절하세요.

> 2026년 들어 “가치가 낮은 콘텐츠” 사유의 거절이 많습니다. 다른 사이트 순위를 모아 보여 주기만 하면 거절되기 쉬우므로, **직접 쓴 해설 글**이 승인의 핵심입니다.

## 8. 다국어 (한국어 · English · 中文 · 日本語 · Español · Français · Русский)

- 방문자 브라우저 언어에 맞춰 자동으로 열리고, 화면 위 🌐 메뉴로 바꿀 수 있습니다. 고른 언어는 다음 방문 때도 유지됩니다.
- 언어별 주소: `https://내도메인.com/?lang=en` 처럼 `?lang=` 을 붙이면 그 언어로 열립니다. 해외 홍보 링크에 쓰세요.
- 숫자 단위(억·만 / B·M / 億·万 / млрд)와 날짜 형식도 언어에 맞게 바뀝니다.
- **순위 화면**은 7개 언어 모두 직접 번역했습니다.
- **소개·개인정보처리방침·해설 글**은 한국어와 영어로 썼고, 중국어·일본어·스페인어·프랑스어·러시아어로 열면 영어판과 함께 “기계 번역으로 보기” 링크가 나옵니다(도메인 연결 후 작동).
- 영상 제목은 원제목을 쓰되, 한국어 원제목과 한국 채널 이름은 번역·로마자로 보여 줍니다.

### 번역 파일 구조

| 파일 | 역할 |
|---|---|
| `i18n/source.js` | 번역할 한국어 원문 목록 (`ui` 화면 문구, `data` 순위 데이터 문구) |
| `i18n/en.js` 등 | 언어별 번역. **source.js와 같은 순서**로 들어 있습니다 |

- 번역이 없는 문구는 영어 → 한국어 순서로 대신 보여 줍니다.
- 순위 데이터가 매일 바뀌면 새 문구(기준일 설명 등)도 번역해 이 파일들에 추가해야 합니다. 매일 0시 Claude 예약 작업이 이 작업을 함께 합니다.
- 언어를 더 늘리려면 `i18n/` 에 새 파일(예: `de.js`)을 만들고, `index.html` 의 `LANGS` 목록과 `<script src="i18n/de.js">` 한 줄을 추가하면 됩니다.

## 9. 앱으로 쓰기 (설치형 웹앱)

이 사이트는 **설치형 웹앱(PWA)** 입니다. 앱스토어를 거치지 않고도 휴대폰 홈 화면에 아이콘으로 설치해 앱처럼 쓸 수 있습니다.

**화면 구성**
- 휴대폰으로 열거나 설치해서 열면 **앱 화면**으로 바뀝니다. PC에서는 지금의 웹사이트 화면 그대로입니다.
  - 위: 앱 바(로고 · 언어) + 분야 칩(옆으로 밀어서 선택)
  - 가운데: 지역 전환, 시상대, **실시간 / 누적** 전환 버튼(한 번에 하나씩 크게)
  - 아래: 탭 메뉴 — 순위 · 검색 · 해설 · 기록 · 정보
  - 영상 플레이어는 아래에서 올라오는 시트로 열립니다.
- PC에서 앱 화면을 미리 보려면 주소 끝에 `?app=1` 을 붙이세요.

**설치 방법 (방문자 안내용)**
- 안드로이드(크롬): 화면에 나오는 **앱 설치** 버튼을 누르면 바로 설치됩니다.
- 아이폰(사파리): 아래쪽 **공유** 버튼 → **홈 화면에 추가**. 처음 방문하면 이 안내가 자동으로 나옵니다.
- 설치하면 주소창 없이 전체 화면으로 열리고, 아이콘을 길게 누르면 “음악 순위 · 스포츠 순위 · 오늘의 해설” 바로가기가 나옵니다(안드로이드).

**오프라인**
- 한 번 열어 본 화면은 저장되어, 인터넷이 끊겨도 마지막으로 받은 순위를 보여 줍니다(위에 오프라인 안내 표시).
- 순위·조회수 데이터는 항상 최신을 먼저 받아 옵니다.
- 화면 코드(index.html 등)를 고쳐 올릴 때는 `sw.js` 맨 위 `VERSION` 값을 바꿔야 방문자 폰에도 새 화면이 바로 반영됩니다. (매일 바뀌는 순위 데이터는 바꿀 필요 없음)

**앱스토어에 올리고 싶다면**
- 이 사이트를 내 도메인(https)에 올린 뒤 https://www.pwabuilder.com 에 주소를 넣으면 **구글 플레이**용 앱 꾸러미를 만들어 줍니다. 구글 플레이 개발자 계정이 필요합니다.
- **애플 앱스토어**도 같은 곳에서 꾸러미를 만들 수 있지만 맥(Xcode)과 애플 개발자 계정이 필요하고, 웹사이트를 그대로 감싼 앱은 심사에서 거절될 수 있습니다. 아이폰은 “홈 화면에 추가” 방식으로 먼저 운영해 보시길 권합니다.

| 파일 | 역할 |
|---|---|
| `manifest.webmanifest` | 앱 이름·아이콘·색·바로가기 |
| `sw.js` | 오프라인 저장 (서비스 워커) |
| `icons/` | 앱 아이콘 (192·512·마스커블·아이폰용) |
| `store/` | 구글 플레이 등록용 설명문·이미지 |
| `.well-known/assetlinks.json` | 앱–사이트 연결 (스토어 앱용) |
| `.nojekyll` | GitHub Pages가 `.well-known` 폴더를 공개하도록 하는 빈 파일 |

## 10. 구글 플레이 등록 (준비물 완료)

`store/` 폴더에 등록에 필요한 것을 모두 넣어 두었습니다.

| 준비물 | 파일 |
|---|---|
| 스토어 설명문 (한국어·영어, 글자 수 제한 확인 완료) | `store/listing.md` |
| 그래픽 이미지 1024×500 | `store/feature-graphic-ko.png`, `-en.png` |
| 휴대전화 스크린샷 1080×1920 (4장씩) | `store/screenshots/ko_*.png`, `en_*.png` |
| 앱 아이콘 512×512 | `icons/icon-512.png` |
| 앱–사이트 연결 파일 (지문만 채우면 됨) | `.well-known/assetlinks.json` |

**순서**

1. **먼저 사이트를 내 도메인(https)에 올립니다** (1~4번). 앱은 이 사이트를 그대로 보여 주므로 사이트가 먼저 있어야 합니다.
2. **구글 플레이 개발자 계정**을 만듭니다(https://play.google.com/console, 등록비 1회).
   - **개인 계정**은 정식 출시 전에 **테스터 12명 이상이 14일 연속 참여한 비공개 테스트**를 마쳐야 합니다. 가족·지인 12명 이상을 미리 모아 두세요.
   - **사업자(조직) 계정**은 이 요건이 없지만 D-U-N-S 번호 발급에 시간이 걸립니다.
3. **앱 꾸러미 만들기**: https://www.pwabuilder.com 에 내 도메인을 입력 → Package for stores → **Android** → Google Play.
   - 패키지 ID: 예 `kr.today1.app` (한 번 정하면 못 바꿉니다)
   - 앱 이름: `오늘의 1위`, 시작 주소 `/?source=app`, 상태바 색 `#ff1f3d`
   - 내려받은 묶음에 **.aab 파일**(스토어 업로드용)과 **서명 키 파일·암호**가 들어 있습니다. **서명 키와 암호는 절대 잃어버리면 안 됩니다.** 안전한 곳 두 군데에 보관하세요.
4. **앱–사이트 연결**: `.well-known/assetlinks.json` 의 `package_name` 을 3번의 패키지 ID로, `sha256_cert_fingerprints` 를 지문으로 바꿔 올립니다.
   - 지문은 **두 개**를 넣으세요: PWABuilder 묶음에 있는 지문 + 플레이 콘솔 → 설정 → **앱 서명** 화면의 “앱 서명 키 인증서 SHA-256”.
   - 이 파일이 맞지 않으면 앱 위쪽에 주소창이 보이게 됩니다.
   - `https://내도메인/.well-known/assetlinks.json` 이 열리는지 확인하세요. (`.nojekyll` 파일이 있어야 GitHub Pages가 이 폴더를 공개합니다 — 이미 넣어 두었습니다.)
5. **플레이 콘솔에서 앱 만들기** → `store/listing.md` 의 문구와 이미지를 넣고, 아래 설문에 답합니다.
   - **개인정보처리방침 URL**: `https://내도메인/privacy.html`
   - **광고 포함 여부**: 예 (애드핏·애드센스를 붙인 경우)
   - **데이터 보안**: 앱이 직접 모으는 개인정보는 없음. 단, 광고를 붙였다면 “광고 ID 등 기기 식별자를 광고 목적으로 수집·공유”를 표시합니다.
   - **대상 연령**: 13세 이상으로 선택하세요. 키즈 영상이 순위에 나오지만 어린이 전용 앱이 아니며, 어린이 대상으로 고르면 별도 정책(가족 정책)을 지켜야 합니다.
   - **콘텐츠 등급**: 설문에서 “사용자 생성 콘텐츠/외부 동영상 링크 포함”에 답합니다.
